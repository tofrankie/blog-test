## 流程图

### 示例一

```mermaid
graph TD
    %% 阶段一：配置初始化与修改
    subgraph Stage1 [1.配置修改阶段]
        Start([开始初始化 Vite]) --> HookConfig[执行所有插件的 config 钩子]
        HookConfig -->|允许修改/合并配置| MergeConfig[合并用户配置、环境变量与插件配置]
    end

    %% 阶段二：插件顺序重组（完全体执行顺序）
    subgraph Stage2 [2. 插件顺序重组与管道执行]
        MergeConfig --> P1[1.Alias 核心插件 <br/> 处理路径别名]
        P1 --> P2[2.用户插件 enforce: 'pre' <br/> 优先于核心逻辑，适合前置转换]
        P2 --> P3[3.Vite 核心插件 Core Plugins <br/> 内部基础构建逻辑]
        P3 --> P4[4.普通用户插件 无 enforce <br/> 严格按照 plugins 数组中的先后顺序执行]
        P4 --> P5[5.Vite 构建插件 Build Plugins <br/> 处理 HTML、CSS 压缩等]
        P5 --> P6[6.用户插件 enforce: 'post' <br/> 绝大多数打包逻辑之后，适合后处理]
        P6 --> P7[7.Vite 后置构建插件 Post Plugins <br/> 最后的打包优化 Minify / Manifest]
    end

    %% 阶段三：配置冻结
    subgraph Stage3 [3.配置冻结阶段]
        P7 --> HookResolved[触发 configResolved 钩子]
        HookResolved -->|完全合并并冻结| Freeze[配置对象转为【只读】 <br/> ❌ 绝对无法再修改配置]
    end

    %% 后续生命周期
    Freeze --> NextStage([进入后续生命周期 <br/> 如 configureServer 或 启动 Rollup 构建])

    %% 样式调整
    style Start fill:#f9f,stroke:#333,stroke-width:2px
    style HookConfig fill:#bbf,stroke:#333,stroke-width:2px
    style HookResolved fill:#ff9,stroke:#333,stroke-width:2px
    style Freeze fill:#f99,stroke:#333,stroke-width:2px
    style NextStage fill:#9f9,stroke:#333,stroke-width:2px
```

### 示例二

```mermaid
graph TD
    Start([开始初始化Vite]) --> HookConfig[执行所有插件的config钩子]
    HookConfig --> MergeConfig[异步串行合并所有配置]

    MergeConfig --> P1[第一步 Alias核心插件处理路径别名]
    P1 --> P2[第二步 用户插件 enforce pre 优先执行]
    P2 --> P3[第三步 Vite核心插件 Core Plugins]
    P3 --> P4[第四步 普通用户插件 按plugins数组顺序执行]
    P4 --> P5[第五步 Vite构建插件处理HTML和CSS等]
    P5 --> P6[第六步 用户插件 enforce post 后置处理]
    P6 --> P7[第七步 Vite后置构建插件 最后的打包优化]

    P7 --> HookResolved[触发 configResolved 钩子]
    HookResolved --> Freeze[配置完全合并并冻结为只读]
    Freeze --> NextStage([进入后续生命周期如启动服务器或构建])

    %% 极简样式
    style Start fill:#f9f,stroke:#333
    style HookConfig fill:#bbf,stroke:#333
    style HookResolved fill:#ff9,stroke:#333
    style Freeze fill:#f99,stroke:#333
    style NextStage fill:#9f9,stroke:#333
```
